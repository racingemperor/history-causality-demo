# 知因 · 历史因果实验室

第一次鸦片战争「五层因果填空 + 阶梯式提示」交互教学 demo。

在线体验：https://racingemperor.github.io/history-causality-demo/

## 学习流程

1. **前测**：主观简答，按层级区分 4 分、时序 3 分、传导关系 3 分给出规则辅助参考。不会可直接进入画布，前测缺失不会记为 0 分；达到 8 分可自主跳过训练。
2. **五层推演**：表层诱因、直接原因、中层核心矛盾、间接原因、深层根本原因。每层可自主填写并单独校验，支持预设同义表述。
3. **阶梯提示**：每层首次求助只展示轻提示，第二次求助才展开深提示。不会直接填入或展示标准答案。
4. **因果连接**：五层全部通过后，从深层向事件写出四段推动关系。
5. **后测与回顾**：更换设问角度，沿用相同评分维度，展示前后测对照，支持原文、校验尝试与提示次数的 JSON 导出。

浏览器自动保存本机进度；「学习说明」中可清空记录。无账号、无学生数据上传、无外部字体或运行依赖。

## 本地运行

直接打开 `index.html`，或在本目录运行：

```sh
python -m http.server 8765
```

访问 http://localhost:8765 。逻辑检查：

```sh
node --test logic.test.cjs
```

GitHub Pages 采用 `main` 分支根目录发布，无需构建。

## 演示边界

- 这是静态网站，校验库在浏览器运行。学生正常界面不显示标准答案，但源码公开，不能做到真正保密。正式版应把答案库与语义评判放到后端。
- 填空采用概念组匹配，主观题采用关键词、连接词和事件顺序证据；不调用大模型，不能完整理解否定、反事实、倒叙或语义等价。系统明确将分数标为待教师复核的参考结果。
- 连接题只检查具有两个以上相关概念且含因果连接词，不能判断全部关系是否成立。它用于演示学习流程，不是正式测评系统。
- 前后测题型与维度相同，但未经心理测量验证；分数变化不能直接证明教学因果效果。
- 五层是教学支架，不表示真实历史只有一条线性因果链。

## 史实表述

使用“英国对华贸易逆差、工业品销路受限”，避免把逆差等同于所有正当贸易均无利润。使用“白银外流、财政与社会危机”，避免把战前状况概括为全面崩溃。虎门销烟为禁烟运动的代表性事件和导火索；英国政府借禁烟冲突发动侵华战争，根本动因仍需从工业发展与殖民扩张解释。

关键时间点：1839 年虎门销烟，1840 年战争爆发，1842 年《南京条约》签订。
