# 知因 · 历史因果实验室

第一次鸦片战争「五层因果填空 + 阶梯式提示」交互教学 demo。

在线体验：https://racingemperor.github.io/history-causality-demo/

## 学习流程

1. **前测**：主观简答，按层级区分 4 分、时序 3 分、传导关系 3 分给出规则辅助参考。不会可明确点击“跳过”，前测缺失不会记为 0 分；达到 8 分可自主跳过训练。
2. **五层推演**：每次只呈现当前层。检验通过后点击继续，或明确点击“跳过这一层”，才能前进。没有步骤列表和任意层跳转入口。
3. **阶梯提示**：页面顶部“提示”与带边框的“跳过”并排，手机端同样可见。提示默认隐藏，主动点击后首次仅展示轻提示，再点击面板内“再看深提示”才展开二级；顶部“收起提示”可随时折叠，再次展开不增加次数。刷新或切换题目后默认收起，已使用级别独立保存并随记录导出。前后测与连接题提供作答方法提醒，不会直接填入或展示标准答案。
4. **因果连接**：五层依次完成或跳过后，从深层向事件写出四段推动关系。页面上方“跳过”可略过当前阶段，跳过状态会随记录导出。
5. **后测与回顾**：更换设问角度，沿用相同评分维度，展示前后测对照，支持原文、校验尝试与提示次数的 JSON 导出。

浏览器自动保存本机进度并兼容旧版记录；「学习说明」中可清空记录。无账号、无外部字体、无构建依赖。

## 语音输入

前测、后测、每层填空、因果连接框均可点击“语音输入”。采用浏览器 `SpeechRecognition` / `webkitSpeechRecognition`，普通话识别，支持停止、实时预览与已识别文字编辑。结果插入光标处，不覆盖已有作答；离页、切换作答或隐藏页面时停止识别，忽略旧会话迟到的结果。

需 HTTPS（GitHub Pages 已开启）或 localhost、麦克风权限及浏览器支持。识别可能依赖浏览器厂商的在线服务，设备、地域及网络会影响可用性；本网站不保存录音，也不自建音频上传服务。不可用时显示具体原因，并提示使用系统键盘的语音功能。

## 评分算法

`assessment.js` 按本专题的概念组、同义表达、否定作用域、相关传导关系及事件时间证据判断，**不计算与标准句的字面相似度**，也不要求固定连接词或先后叙述顺序。常见口语、描述性作答、引用后反驳及倒叙论证可获得满分。

找不到足够证据的维度返回 `null`，界面显示“待复核”，不折算为 0 分，也不计算总分或提升。识别到明确错误（例如把销烟认作根本原因、颠倒正常贸易顺逆差、具体年份错误）则提供相应反馈。导出文件包含概念、关系原文和冲突证据，便于复核。

没有内置小模型。局部领域规则可解释、加载快，但不能完整理解任意自然语言，不能承诺所有改写均正确判定。后续若用于正式测评，建议用真实学生作答与教师标注建立独立验证集，再决定是否增加更强的语义服务。

## 本地运行

直接打开 `index.html`，或在本目录运行：

```sh
python -m http.server 8765
```

访问 http://localhost:8765 。逻辑检查：

```sh
node --test logic.test.cjs assessment.test.cjs voice.test.cjs
```

GitHub Pages 采用 `main` 分支根目录发布，无需构建。

## 演示边界

- 这是静态网站，校验库在浏览器运行。学生正常界面不显示标准答案，但源码公开，不能做到真正保密。正式版应把答案库与语义评判放到后端。
- 填空与主观题使用专题概念和关系规则，已扩展同义与描述性表达，但复杂省略、否定、反事实或域外表述仍可能误判，分数仅为参考。
- 连接题检查相关概念及传导线索，不能完整证明论证成立。它用于演示学习流程，不是正式测评系统。
- 前后测题型与维度相同，但未经心理测量验证；分数变化不能直接证明教学因果效果。
- 五层是教学支架，不表示真实历史只有一条线性因果链。

## 史实表述

使用“英国对华贸易逆差、工业品销路受限”，避免把逆差等同于所有正当贸易均无利润。使用“白银外流、财政与社会危机”，避免把战前状况概括为全面崩溃。虎门销烟为禁烟运动的代表性事件和导火索；英国政府借禁烟冲突发动侵华战争，根本动因仍需从工业发展与殖民扩张解释。

关键时间点：1839 年虎门销烟，1840 年战争爆发，1842 年《南京条约》签订。
